## 2. 価格設計（C案・裁定後）

- **フリーミアム**: 無料 = レシピ3件・保存はローカルのみ・エクスポートなし
- **Pro**: **¥980/月** または **¥9,800/年**（2ヶ月分お得 — 現金前倒し＋チャーン抑制）
  - 解放: レシピ無制限・PDF/CSV出力・値上げシミュレーション・原価率アラート
- **決済**: Stripe Payment Link + ライセンスキー（バックエンド不要）
- **価格根拠**: 原価計算女王 ¥7,800/年（Windows専用・UI古）がアンカー。ブラウザ完結・即時再計算・シミュレーションの付加価値で年額¥9,800は防御可能。¥980/月は「原価ミス1品で消える額」

## 5. 最大の財務リスクと対策

- **リスクは需要側（獲得・維持）**: 純利益率~96%のため、コストは脅威にならない。広告費ゼロで306件の獲得・維持がすべて。月次チャーン5%ならLTV ~¥19,600（20ヶ月）、10%なら半減し月~30件の補充が必要。
- **対策**: (a) フリーミアム＋SEOでCAC¥0の獲得ファネル、(b) 年額プランで現金前倒し＋チャーン抑制、(c) 「食材価格更新→全メニュー即時再計算」の反復価値でスイッチングコストを構築（データ蓄積型のリテンション）。
