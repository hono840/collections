### C-Suite間の意見相違と裁定（記録）

- **CFO** は F（シフト表, ¥1,480/月フラット）を財務面で推奨（サブスク複利・純利益率95.6%・必要顧客数最少）。
- **CSO**（market-researcher + competitive-analyst の両調査）は C を推奨し、F は「良質な自動生成を数日で作れない＝WTPに到達不能」として**制約ゲートで除外**。
- **裁定**: C を採用。ただし CFO の「買い切りは毎月ゼロリセットの踏み車」という批判を取り込み、**Cをサブスクリプション型（月額/年額）で設計**する。食材価格変動→全メニュー原価率の即時再計算という反復利用がサブスクを正当化する。

## 市場機会 (CSO → market-researcher + competitive-analyst)

- **市場規模**: 飲食店 約55万事業所（令和3年経済センサス）。うち原価管理に能動的な個人店オーナー層 ~10-15万と推定。
- **ペイン**: 高くかつ**反復的**。食材価格高騰局面でメニュー再値付けが恒常化。現状はExcel/電卓/手書きで、計算ミス・関数破損・時間浪費の不満が多数。
- **WTP実証**: 原価計算女王 for飲食（¥7,800/年・Windows専用・UIが古い）、Fillet（グローバルSaaS・日本ローカライズ弱）、のびしろFood（スマレジPOS契約必須・300メニューで¥20-35万）、有料note原価計算シートが売れている（「Excelシートにすら金を払う層」の存在）。
- **競合の穴（wedge）**: 「**POS非依存・ブラウザ完結・登録不要・食材価格を更新すると全メニューの原価率が即時再計算・値上げシミュレーション・データは端末内のみ**」を満たす製品が不在。
- **SEO勝機**: 「飲食店 原価計算」「原価率 計算」等のSERPは note記事・Excelテンプレ配布が主戦場で、大手SaaSが未占有。6候補中唯一ソロのコンテンツSEOで勝てるレーン。
- **ポジショニング文**: 「POS契約も会員登録も不要、スマホとブラウザだけで完結。食材費が変わると全メニューの原価と原価率が即座に再計算され、値上げ額と目標原価率をその場でシミュレーションできる、個人店のための原価計算ツール。」

### 狙うSEOキーワードクラスタ

1. **原価計算コア**（高意図・SaaS不在SERP）: 飲食店 原価計算 / メニュー 原価計算 / 原価率 計算 方法 / 原価率 計算 ツール
2. **値上げ・値付け**（インフレで上昇トレンド）: メニュー 値上げ 計算 / 値付け / 適正価格
3. **Excel乗り換え**（WTP実証済み層）: 原価計算 エクセル テンプレート / 原価計算表 無料 / レシピ 原価 計算
4. **ロングテール権威**: 歩留まり 計算 / ロス率 / 原価率 30%

## 到達タイムラインと確度（正直な評価）

- Week 1-2: MVP構築・磨き込み（本セッションで実施）
- Month 1-3: note.com + ブログSEO + X飲食店オーナーコミュニティ → 有料 20-50件
- Month 4-9: SEO複利 → 100-200件
- Month 9-18: 306件+ = 月30万円到達
- **確度: 18ヶ月以内で40-50%**（SEO複利とチャーン制御に依存。飲食系インフルエンサーの増幅があれば前倒し）
- ⚠️ 「サクッと即月30万」を保証するアプリは存在しない。本選定は「ソロ運営・広告費ゼロ・低固定費」制約下で**最も確度の高い経路**の選択である。

## リスクと対策

1. **低ARPU天井**（¥7,800/年アンカー）→ 年額課金でLTV確保。将来 ¥1,480 上位プラン（メニュー表PDF・仕入記録）でARPU引き上げ
2. **チャーン**（開業時に1回計算して離脱）→ 反復化を製品に内蔵: 食材価格更新→即時再計算、原価率アラート、季節再値付けプロンプト、月次利益スナップショット
3. **SEOが306件まで複利しない** → 無料クライアントサイドツールをSERPベイトに、Excelインポートでスプレッドシート層を奪取、フリー機能の規律あるゲーティング

## 推奨アクション

1. C（飲食店メニュー原価計算）のMVPを直ちに構築（`/new-app` フロー）
