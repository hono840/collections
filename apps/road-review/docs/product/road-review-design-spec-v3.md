## 1. 新しい前提（2026-10-10 の CEO の方針）

- 主な機能は「名前のある道を探す」。打っている途中で候補が出る（6件まで・都道府県つき）。
- 候補を選ぶと道の詳細。地図（Leaflet＋地理院タイル）の上で、道を約1.5秒でなぞる。
- 「道の登録」は「♡ お気に入り」に変わる。外したときは「元に戻す」。
- 「自分で道を追加」は、検索が0件のときだけ出す。
- 速さをあおる動き・言葉を使わない（DS v2 1章の「レースを思わせる見た目を使わない」を広げる）。

## 2. 原則（DS v2 の4つに1つ足す）と「記憶に残る一点」の変更

DS v2 の原則1〜4（1画面=1つの仕事／主な操作は下に文字つきで1つ／色には意味がある・色だけで伝えない／外で読める）はそのまま。足すもの:

5. **探すのは上、行動は下。** 文字を打つ部品（検索欄）はキーボードに隠れない**上**に置く。押して決める操作（お気に入りに追加・記録を追加・保存）は親指の届く**下**に置く。ホームの主な操作は検索なので、ホームには下の主ボタンのバーを置かない（UX 調査 2-1）。

**記憶に残る一点（DS v2 2章を置き換え）**: **「道の色で、道の形がなぞられる」**。道の詳細を開くと、種類の色の帯の下で、その道が同じ色の線で始まりから終わりへ描かれる。v2 の見せ場だった「ホームの色の帯が伸びる動き」は**やめる**（見せ場を1つに保つ。UX 調査 7章）。色の帯は、お気に入りの画面のまとめに**動かない**形で残す。

## 3. ナビゲーション（DS v2 3章を置き換え）

- 下のタブバーは作らない（DS v2 と同じ）。
- 行き先は「ホーム（探す）」「お気に入り」「データ」。
  - ホームの上のバーの右に「⇅ データ」（DS v2 と同じ）。
  - **お気に入りへの入口はホームの中**（「お気に入り」の見出しの右の「すべて見る（N本）›」）。お気に入りの画面の上のバーは「‹ ホーム」。
- 下の主ボタンのバーを置く画面: 道の詳細（「♡ お気に入りに追加」か「＋ 走った記録を追加」）、フォーム（保存）、案内。**置かない画面**: ホーム・検索・結果の一覧・お気に入り・データ。
- 検索は「全画面の検索」に切り替わる（Material 3 の「検索バー → 広がった検索の画面」。UX 調査 G1）。上のバーの代わりに［‹］・入力欄・［×］の行が出る。

## 4. デザイントークン

**DS v2 4-1〜4-6 をそのまま使う**（色・種類の色・コントラスト・文字・余白・角の丸み・影）。v3 で変える・足すのは 4-7〜4-10 だけ。

### 4-7. 動き（DS v2 4-7 を置き換え）

| トークン | 値 | 用途 |
|---|---|---|
| duration-press | 100ms | 押した瞬間の色（v2 のまま） |
| duration-base | 200ms | シート・トースト・開閉・終わりの印が現れる（v2 のまま） |
| **duration-trace** | **道の長さで 1200〜2000ms**（5km → 1300ms、15km → 1500ms、40km 以上 → 2000ms。計算は ARCH v3 7.3） | 道をなぞる動き |
| **ease-trace** | `cubic-bezier(0.37, 0, 0.63, 1)`（ゆっくり始まり、ゆっくり終わる。だんだん速くなる形にしない） | 線が1本の道のなぞる動き。2本以上のときは各線 `linear` |
| **trace-tile-wait** | 最大 500ms | なぞる前に地図の画像を待つ時間の上限 |
| **duration-toast** | 4000ms | ふつうのトースト（v2 のまま） |
| **duration-toast-undo** | **8000ms** | 「元に戻す」つきのトースト（UX 調査 2-6）。フォーカスかポインターが乗っている間は止める |
| ease-standard | cubic-bezier(0.2, 0, 0, 1) | 共通（v2 のまま） |
| ~~duration-reveal~~ | **やめる** | v2 の色の帯の伸びる動きは作らない |

- **見せ場は1つだけ**: 道の詳細のなぞる動き。ホーム・お気に入り・検索の候補には、現れる動き・ずれる動きを付けない（候補は打つたびにすぐ入れかえる。フェードもしない＝打つ速さについてこられるように）。
- **あおらない決まり**（PRD v3 US-07・US-14）: 動く点・車やバイクの絵・矢印・残像・速さの線・カメラが追いかける動き（地図が線の先に合わせて動く）・だんだん速くなる動き・ゆれ・効果音・振動を使わない。地図は最初に道全体に合わせたら動かさない。
- `prefers-reduced-motion: reduce` のとき: 全部の時間を 0.01ms に（v2 のまま）。**なぞる動きは最初から全部描いた線**、「もう一度なぞる」は出さない、終わりの印も最初から出す。トーストはフェードだけ。

### 4-8. 道の線と地図の印（新規）

| 部品 | 見た目 | 根拠 |
|---|---|---|
| 道の線 | 種類の **solid** 色（DS v2 4-2）、太さ 5px、端と角は丸（`round`） | UX 調査 2-5 |
| 線のふち | 線の下に白（#FFFFFF）の線、太さ 9px（線の両側に 2px ずつ見える） | 淡い地図の上でも線が埋もれない（UX 調査 5-4） |
| 始まりの印 ● | 半径 6px、solid で塗る、白いふち 2px | 「どこから」が分かる |
| 終わりの印 ○ | 半径 6px、白で塗る、solid のふち 3px | 「どこまで」が分かる（形でも始まりと区別） |
| 地図の枠 | 高さ **240px**（360px 幅でも同じ）、radius-md、1px line の枠 | 本文がずれない（PRD v3 MB-14） |
| 地図の出典（右下） | 「© OpenStreetMap」「地理院タイル」の2つのリンク。text-caption（13px）、ink、surface の不透明度 0.85 の地、左右 6px | DS v2 6-12 と同じ形に OSM を足す |

**コントラスト（手計算・新しい組み合わせ）**
| 組み合わせ | 比 | 基準 |
|---|---|---|
| 各 solid の線 / 白いふち | 白 / solid と同じ: 峠 5.2・スカイライン 5.7・海岸線 5.5・林道 5.0・その他 6.0 | 部品 3:1 ✔ |
| 白いふち / 淡色地図の地（明るい灰 #F2F2F2 前後と仮定） | 約1.1 | ふちは区切りのためで、線の見え方は solid と地図の比で見る |
| 各 solid / 淡色地図の地（#F2F2F2 と仮定） | 峠 4.6・スカイライン 5.1・海岸線 4.9・林道 4.5・その他 5.4 | 部品 3:1 ✔ 【未確認: 地理院の淡色地図の実際の色は場所で違う（森の緑・水の青）。実装後に、林道（緑）が森の上、海岸線（青緑）が海の上で見えるかを画面写真で確かめる】 |
| ink の出典の文字 / surface 0.85 の地（地図の上） | 約14 | 本文 ✔ |

### 4-9. 検索の候補（新規）

| 項目 | 値 |
|---|---|
| 候補の1行 | 高さ 56px 以上（2行になれば伸びる）、左右 16px、上下 8px。行全体が押せる |
| 種類の箱 | 40×40px、radius-sm、solid の地に白い記号 22px（DS v2 6-4 の箱の小さい版） |
| 名前 | text-body（16px）、ink、400。**打った言葉に合った部分は 700（太字）**。色は変えない（色だけで伝えない） |
| 2行目 | 都道府県（text-small 14px、ink-muted）＋ 2文字分あけて種類名。読みで当たったとき・別名で当たったときは、名前の下に「うすいとうげ」「別名: 船原西浦高原線」（text-small、ink-muted） |
| お気に入り済み | 行の右に「♥」（16px、ink）＋読み上げ用の文字「お気に入り」 |
| 選ばれている行（キーボードの ↑↓） | 地を primary-tint、左に 4px の primary の縦線（形でも分かる） |
| 押した瞬間 | 地を bg |
| 区切り | 行の間に 1px line（飾り） |
| 「すべて見る」の行 | 高さ 52px、primary の文字 700「『スカイライン』の道をすべて見る（12件）」＋「›」 |
| 件数（読み上げ用） | 一覧の上の小さな文字「候補 6件」（text-caption、ink-muted）。画面にも出す |

### 4-10. トースト（DS v2 6-10 に足す）

- 「元に戻す」つき: ink の地・bg 色の文字（v2 のまま）、右に［元に戻す］（text ボタン、文字は #9DC0FF【計算: ink #15202B の上で約9.0:1】、700、押せる範囲 44px）。
- 置き場所: 下の主ボタンのバーの上 12px（バーがない画面では画面の下から 16px＋safe-area）。左右 16px。
- 同時に出すトーストは1つ。新しいトーストが来たら前のトーストを入れかえる。
- 地図の出典との関係: 画面を開いた直後（スクロールしていない状態）では、地図は画面の上半分にあり、トーストは下のバーの上なので重ならない【推論: 360×640 で地図の下端は約 416px、トーストの上端は約 496px】。スクロールの途中で一時的に重なることはありうるので、**出典は地図の下の出典の行（PRD v3 US-19。44px）にも必ず出す**。地図の隅の出典の場所は動かさない（決まった場所に置く）。確認は PRD v3 MB-13 の画面写真（トーストを出した状態）で行う。

## 6. 部品の仕様（v3 で足す・変えるもの）

DS v2 6章の共通の決まり（フォーカスの枠・ホバーは `hover: hover` の中だけ・`scroll-padding`）はそのまま。

### 6-1. 検索のコンボボックス（SearchCombobox。organisms）
- 入力欄: `role="combobox"`、`aria-expanded`（候補が出ていれば true）、`aria-controls`（一覧の id）、`aria-autocomplete="list"`、見えるラベル（「道の名前で探す」。入力欄の上に text-small 700。画面が狭いので視覚的には入力欄の左上に小さく置いてもよいが、`aria-label` だけにはしない）。`type="search"`、`enterkeyhint="search"`、`autocomplete="off"`、`autocapitalize="off"`、`spellcheck="false"`、文字 16px、高さ 52px。
- 一覧: `role="listbox"`、各行 `role="option"`、選ばれている行は入力欄の `aria-activedescendant`。フォーカスは入力欄のまま（UX 調査 A1）。
- キー（変換中は全部 IME に任せる。ARCH v3 5.5）: ↓ 最初の行へ／↑ 最後の行へ／Enter 選ばれた行があればその詳細、なければ結果の一覧／Esc 候補を閉じる → もう一度で入力欄を空にする。
- ［×］: 入力欄を空にしてフォーカスを入力欄に戻す（`aria-label="入力を消す"`）。［‹］: ホームへ戻り、フォーカスをホームの検索欄に戻す。
- 件数の読み上げ: 一覧の外の `role="status"`。最後の入力から 500ms 後に1回。

### 6-2. 候補の行（SuggestionRow。molecules）
4-9 のとおり。読み上げ名の例: 「ヤビツ峠、神奈川県、峠、読み やびつとうげ」「西伊豆スカイライン、静岡県、スカイライン、お気に入り」。太字の部分は `<strong>` にする（`<mark>` は使わない。色を付けないため）。

### 6-3. ホームの検索欄（SearchLauncher。molecules）
見た目は入力欄（52px・虫めがねの記号 20px・案内文 ink-muted）。中身は `button`。押すと検索の全画面を開き、入力欄にフォーカスを移す。

### 6-4. 道のカード（RoadCard。DS v2 6-4 を置き換え）
- DS v2 6-4 の形（左に種類の箱 48×48、右に名前・都道府県と種類バッジ・評価と回数）に、**右上の ♡/♥ ボタン**（44×44px。カードのリンクとは別の `button`。カードのリンクの中に入れ子にしない）を足す。
- 都道府県は複数のとき「神奈川県、静岡県」（3県以上は「ほか N県」）。
- 結果の一覧では評価と回数の行の代わりに種類名だけ（記録がない道が多いため）。お気に入り・ホームでは v2 のまま。
- 読み上げ: カードのリンク「ヤビツ峠、神奈川県、峠、総合評価 平均4.0、2回走った」／ボタン「ヤビツ峠をお気に入りから外す」（`aria-pressed` ではなく、何が起きるかを名前にする。一覧の中で同じ名前のボタンが並ぶのを避けるため）。

### 6-5. お気に入りのボタン（2つの形）
| 形 | 置き場所 | 見た目 | 状態 |
|---|---|---|---|
| FavoriteAction（主ボタン） | 道の詳細の下のバー | primary 56px、「♡ お気に入りに追加」（ふちだけの ♡ 20px） | お気に入りになったら、このボタンは「＋ 走った記録を追加」に入れかわる |
| FavoriteToggle（小） | 道の詳細の帯の右上 | 44px、透明の地・白い 2px の枠・白い文字「♥ お気に入り」（塗った ♥） | `aria-pressed="true"`。押すと外す。お気に入りでないときは出さない |
| カードの ♡/♥ | 6-4 | 44px、ink の記号（♡ はふち、♥ は塗り） | 上の読み上げ名 |
- ♥ に赤やピンクの色を使わない（色の意味を「道の種類」と「操作の青」に限る。DS v2 原則3）。記号の塗り／ふちと文字で状態を伝える。
- 押した瞬間の動きは duration-press の色の変化だけ（はねる・広がる動きはしない）。

### 6-6. トースト（UndoToast。DS v2 6-10 のトーストに足す）
4-10 のとおり。［元に戻す］を押したら、文を「元に戻しました」に変え、2秒で消す。失敗のトーストは v2 のまま（自動で消さない・［もう一度］・`role="alert"`）。

### 6-7. 道の形の地図（RouteMap。organisms）

## 7. なぞる動きの仕様（まとめ）

**ゴール**: 道の形を「始まり → 終わり」の流れでつかめる。速さは感じさせない。
→ **そのために** 地図は止めたまま、線だけを一定に近い速さで、1回だけ伸ばす。
→ **さらにそのために** 時間は道の長さで少しだけ変える（短い道で速すぎ・長い道で長すぎにならない）。

| 項目 | 決まり |
|---|---|
| きっかけ | 道の詳細を開いたとき（画面が見えているとき）に1回。「もう一度なぞる」で1回 |
| 前に待つもの | 地図を道全体に合わせる → 地図の画像を最大 500ms 待つ |
| 順番 | ①始まりの●を出す ②線（白いふちと色の線を同時に）が伸びる ③終わりの○が 200ms で現れる |
| 時間 | duration-trace（1200〜2000ms） |
| 速さの変わり方 | 線が1本: ease-trace（ゆっくり始まりゆっくり終わる）／2本以上: 各線一定で順番に |
| くり返し | しない |
| 地図 | 動かさない（拡大・移動・回転・追いかけをしない） |
| 動きを減らす設定 | 最初から全部描く。●と○も最初から。「もう一度なぞる」なし |
| 途中で押されたもの | 「もう一度なぞる」→ 最初から。♡ や戻るは、動きを待たずにすぐ効く |
| 画面が隠れたとき | 見えるまで始めない。途中で隠れたら、そのまま終わらせる（戻ったときに全部描いてある） |
| 使わない物 | 動く点・車やバイクの絵・矢印・残像・速さの線・効果音・振動・数字（距離や時間）の表示 |
| 読み上げ | 動きは読まない。地図の名前で道を伝える |

## 8. frontend-developer への実装指示

### 8-1. 部品の対応（Atomic Design。依存は atoms ← molecules ← organisms ← templates の一方向）

DS v2 7-2 の表に足す・変えるもの:

| 階層 | v3 で足す・変える部品 |
|---|---|
| atoms | PrefectureLabel（新）、HeartIcon（♡/♥ の記号。新）、TraceReplayButton（Button の text 形の使い方） |
| molecules | SearchLauncher（新）、SuggestionRow（新）、SeeAllRow（新）、NoResults（新。0件の案内）、CatalogNote（新）、MapAttributionRow（新）、UndoToast（Toast の形を広げる）、ExampleRoads（新。例の道3本） |
| organisms | SearchCombobox（新）、RouteMap（新。v2 の RoadMiniMap は自分で追加した道に残す）、RoadCard（♡ を足す）、FavoriteAction・FavoriteToggle（新）、RoadDetailHeader（帯に ♥ を足す）、CatalogNotesSection（新）、CatalogDataPanel（新。データ画面の「道のデータについて」）、FavoritesSummary（旧 HomeSummary を移した。色の帯は動かない） |
| templates | SearchTemplate（新。入力の行＋中身。上のバーと下のバーなし）、HomeTemplate（検索欄・種類・お気に入りの先頭。下のバーなし）、FavoritesTemplate（新）、RoadDetailTemplate（地図 240px の枠を持つ） |

- 部品は検索の関数・索引・保存処理を import しない（ARCH v3 12章の `noData`）。`SearchCombobox` は `results`・`onQueryChange`・`onSelect`・`onSubmit` を props で受け取る。

### 8-2. 注意点
- 候補の太字は `<strong>`。色を付けない。
- ♥ に色を付けない。
- 地図の枠は最初から 240px。読み込み中は bg の地に何も描かない（スケルトンの動きも付けない）。
- 道の線の色は種類の solid だけ。ほかの色を足さない。
- トーストの位置は下のバーの上。地図の出典に重ねない。
- ホーム・お気に入り・検索・データに、下の主ボタンのバーを置かない。

## 9. スクリーンショット確認チェックリスト（360×640 と 390×844、ライトのみ）

撮る画面と状態の一覧は **PRD v3 9章の表**。DS v2 8章の「全画面共通」の項目はそのまま使う。v3 で足す項目:

- [ ] ♥ に色が付いていない。お気に入りの状態は記号の塗りと文字で分かる
- [ ] 中黒でつないだ県名がない（「、」か「ほか N県」）

**検索**
- [ ] 入力欄が空: 例の道3本と種類のチップが見える
- [ ] 変換中（「やびつ」）: 候補にヤビツ峠、読みが出ている、太字なし
- [ ] 「スカイライン」: 候補が6件まで、合った部分だけ太字、各行に都道府県、一番下に「すべて見る（N件）」
- [ ] 一覧の中にスクロールバーがない
- [ ] キーボードの高さ分を縮めた画面で、入力欄と候補の1件目が見える（360×640）・入力欄と候補の3件目まで見える（390×844）
- [ ] 0件: 打った言葉が残り、案内の2行・種類チップ・「自分で追加」が見える。候補があるときは「自分で追加」が無い

**道の詳細**
- [ ] 途中のコマ（約750ms）: 始まりの●があり、線が途中まで。車・矢印・動く点がない
- [ ] 終わり: ●と○の両方、線が全部
- [ ] 動きを減らす設定: 最初から全部、「もう一度なぞる」が無い
- [ ] 地図の右下の出典（© OpenStreetMap・地理院タイル）が見え、トースト・下のバーに隠れていない
