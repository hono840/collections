# メモの編集 見た目の仕様（AC23〜AC29）

- 書いた日: 2026-10-25 ／ 書いた人: ui-ux-designer
- 原本 `Main.dc.html` に編集の画面は無い。なので原本にある部品だけで組み立てる（見出し「メモ」、追加画面のメモ欄 `.fld`、追加画面ヘッダーの「キャンセル」「保存」）。
- 新しい色・フォント・角丸・影・動きは足さない。`globals.css` は変えない。切り替えは一瞬（動きなし。アプリ全体に動きが無いため）。

## 決めたこと（ひとこと）

見出し「メモ」の右に、ボタンを置く場所を1つだけ作る。読むときは「編集」、書くときは「キャンセル」「保存」がそこに入れ替わる。終わるとフォーカスも同じ場所（「編集」）に戻る。入力欄は追加画面のメモ欄と同じ見た目なので、開いた瞬間にオレンジの枠（フォーカス中のしるし）になる。

## 1. 見出し行と「編集」ボタン

- 見出し行は高さ 44px。44px のボタンをメモ欄に重ねずに置くため。上に 12px 食い込ませる（`-mt-3`）ので、「メモ」の文字の位置は今のまま。メモ欄は今より約5px下がる（見出しとのすき間 8px → 約12px）。
- 「編集」は文字だけのボタン。15px・太字・オレンジ（`text-accent`）。追加画面ヘッダーの「保存」と同じ書き方。原本ではオレンジの文字はいつも太字なので、それに合わせる。
- 読み上げ名は `aria-label="メモを編集"`。見えている「編集」を含むので WCAG 2.5.3 を満たす。
- 文字の右端をメモ欄の右端にそろえる（右の入れ物に `-mr-2`、ボタンに `px-2`）。押せる範囲は 44×44px 以上。
- フォーカスは今の全体ルール（オレンジの線 2px、2px 離す）をそのまま使う。ホバーの見た目は足さない（ほかのボタンにも無い）。

## 2. 編集中の入力欄

- `TextField`（追加画面のメモ欄と同じ部品）を `multiline`・`rows={4}` で使う。見た目のクラスは足さない（枠 `border-edge`・角丸 12px・16px の文字・行間 1.6・`resize-none`）。16px は、iPhone で入力するときに画面が拡大されないため。
- 読むときの箱（角丸 14px・余白 16px・15px の文字）から形が少し変わるのは、わざと。「いま書ける」と分かるようにするため。
- フォーカス中は枠がオレンジ（`focus:border-accent`、今のまま）。編集を始めるとすぐフォーカスが入るので、開いた瞬間からオレンジ。
- メモが空のときの薄い文字は、追加画面と同じ「例：冬は通行止め。帰りに寄りたいお店など」。
- 読み上げ名「メモ」は `aria-labelledby` で見出し h2 を指して付ける。`FormField` は使わない（`label` で「メモ」がもう1つ見えてしまうため）。
- カーソルは文の最後に置く（推奨。あとから書き足すことが多いため）。

## 3. 「キャンセル」「保存」

- 置き場所は見出し行の右（「編集」があった場所）。並びは「キャンセル」が左、「保存」が右。追加画面のヘッダーと同じ並び・同じ見た目。
- キャンセル: 15px・ふつうの太さ・`text-ink-soft`。保存: 15px・太字・`text-accent`。どちらも文字だけ、高さ 44px、幅 44px 以上。
- 「保存」はいつも押せる（押せない見た目は作らない）。空で保存してもよいため（AC24）。
- 入力欄の下に置かない理由: 下には大きい青の「行った！にする」があり、続けて並ぶとどれがメモのボタンか分かりにくい。また見出し行は入力欄のすぐ上なので、キーボードが出ても見える位置に残りやすい（推論）。
- 下の「行った！にする」と削除はそのまま。編集を始めたら、削除の文字は「このスポットを削除」に戻る（AC29）。

## 4. クラス（そのまま使う）

```tsx
<div className="flex flex-col">{/* メモの塊。今の gap-2 は外す */}
  <div className="-mt-3 flex h-11 items-center justify-between">
    <h2 id={memoHeadingId} className="text-13 font-medium text-ink-muted">メモ</h2>
    <div className="-mr-2 flex items-center gap-2">
      {/* 読むとき */}
      <button type="button" aria-label="メモを編集" className="h-11 min-w-11 bg-transparent px-2 text-15 font-bold text-accent">編集</button>
      {/* 編集中（「編集」の代わりに出す） */}
      <button type="button" className="h-11 min-w-11 bg-transparent px-2 text-15 text-ink-soft">キャンセル</button>
      <button type="button" className="h-11 min-w-11 bg-transparent px-2 text-15 font-bold text-accent">保存</button>
    </div>
  </div>
  {/* 読むとき: 今の <p>（クラスは変えない）。編集中: */}
  <TextField multiline rows={4} id={memoFieldId} labelledBy={memoHeadingId} ref={memoFieldRef}
    placeholder="例：冬は通行止め。帰りに寄りたいお店など" value={draft} onValueChange={setDraft} />
</div>
```

- `TextField` に足すもの: `labelledBy`（`aria-labelledby` になる）と、`textarea` にも `ref` を渡せること。見た目（`FIELD_CLASS_NAME`）は変えない。

## 確かめること

- 【未確認】iPhone 実機で、キーボードが出たとき見出し行（キャンセル・保存）が見えるか。隠れるなら、編集開始時にメモの塊を `scrollIntoView({ block: 'start' })` で上へ寄せる。
- キーボード操作では、ボタンが入力欄より前にある（追加画面と同じ並び）。入力欄から Shift+Tab 1回で「保存」に行ける。
- 色の見やすさ（計算値）: オレンジの文字と背景 約7.3:1、キャンセルの文字 約12:1、メモ欄の薄い文字 約4.6:1、オレンジの枠とメモ欄 約6.7:1。文字はどれも 4.5:1 以上。
